## Description

Generate an ASP.NET Core REST API controller as an alternative migration path to gRPC. The controller should expose the same operations as the original WCF service with proper HTTP verbs, routing, and OpenAPI documentation.

---

## Acceptance Criteria

- [ ] Generate ASP.NET Core controller with `[ApiController]` attribute
- [ ] Map WCF operations to appropriate HTTP methods (GET, POST, PUT, DELETE)
- [ ] Include proper route attributes with RESTful conventions
- [ ] OpenAPI ready with `[ProducesResponseType]` attributes
- [ ] Same method signatures as original WCF service
- [ ] Dependency injection ready (constructor injection pattern)
- [ ] Include XML documentation for Swagger generation
- [ ] Handle async operations properly
- [ ] Generate DTOs matching WCF DataContracts
- [ ] Unit tests for controller generation

### HTTP Method Mapping Strategy

| WCF Operation Pattern | HTTP Method | Route |
|----------------------|-------------|-------|
| `Get{Entity}(id)` | GET | `/{id}` |
| `Save{Entity}(entity)` | POST/PUT | `/` or `/{id}` |
| `Create{Entity}(entity)` | POST | `/` |
| `Update{Entity}(entity)` | PUT | `/{id}` |
| `Delete{Entity}(id)` | DELETE | `/{id}` |
| `Search{Entity}(criteria)` | POST | `/search` |
| `List{Entity}()` | GET | `/` |

### Generator Implementation

```csharp
public class RestControllerGenerator
{
    public string Generate(WcfServiceContract serviceContract, List<WcfDataContract> dataContracts)
    {
        var sb = new StringBuilder();

        WriteUsings(sb);
        WriteNamespace(sb, serviceContract);
        WriteClassDeclaration(sb, serviceContract);
        WriteConstructor(sb, serviceContract);

        foreach (var operation in serviceContract.Operations)
        {
            WriteAction(sb, operation);
        }

        WriteClosingBraces(sb);

        return sb.ToString();
    }

    private HttpMethodInfo DetermineHttpMethod(WcfOperation operation)
    {
        var name = operation.Name.ToLowerInvariant();

        if (name.StartsWith("get") || name.StartsWith("find") || name.StartsWith("list"))
            return new HttpMethodInfo("HttpGet", hasIdParameter: operation.Parameters.Count == 1);

        if (name.StartsWith("delete") || name.StartsWith("remove"))
            return new HttpMethodInfo("HttpDelete", hasIdParameter: true);

        if (name.StartsWith("update") || name.StartsWith("modify"))
            return new HttpMethodInfo("HttpPut", hasIdParameter: true);

        if (name.StartsWith("search"))
            return new HttpMethodInfo("HttpPost", route: "search");

        return new HttpMethodInfo("HttpPost");
    }
}
```
