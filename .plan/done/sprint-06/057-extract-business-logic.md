## Description

Extract business logic from WCF service implementations into a shared service layer that can be consumed by both gRPC and REST API endpoints. This ensures clean separation of concerns and DI compatibility.

---

## Acceptance Criteria

- [ ] Clean separation between transport layer and business logic
- [ ] Interface-based design for business services
- [ ] Full dependency injection compatibility
- [ ] Async/await pattern throughout
- [ ] Preserve original business logic behavior
- [ ] Generate interface from WCF service implementation
- [ ] Generate implementation stub with method bodies from WCF
- [ ] Map WCF-specific types to modern equivalents
- [ ] Support transactional boundaries
- [ ] Unit tests for extraction logic
